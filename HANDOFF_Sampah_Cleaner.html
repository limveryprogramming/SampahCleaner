SampahCleaner

Everything is now in one Unity project. The robots walk, the main menu is built, and the menu robot turns 360 degrees. This page lists what is done, how to open it, and what is still missing.

The project

Game
Sampah Cleaner, from the "Trash Tide" concept: a cleaning robot collects trash on a Beach map and an Ocean map in 5-minute rounds, with upgrades, a photo mechanic and four endings.
Engine
Unity 6000.5.8f1 (Unity 6.5), URP, new Input System
Scenes
MainMenuScene (the menu) and SampleScene (the game)

How to open it

Use only this folder Desktop\xsollar new\SampahCleaner_WalkingRobot_Animation
  1. Open Unity Hub, click Add, and choose the folder above.
  2. Open it with Unity 6000.5.8f1.
  3. The first open takes a few minutes because the Library folder is rebuilt.
  4. Open Assets/Scenes/MainMenuScene and press Play.

What was done

One combined project

The animated walking project was found in xsollar_gamejam\SampahCleaner and merged with the new menu work into the folder above. Nothing was deleted from the older copies.

Robots walk forward

Both robots walked backwards on W. The facing angle is now set in RobotController (-90 by default) and on the TrashRobot prefab (180). The LandRobot prefab was also set to -90.

Main menu

Built from the Doc1 mockup: navy background, SAMPAH in teal and CLEANER in orange, a button panel on the right, and a robot card on the bottom left. Buttons change color, brighten their outline and grow slightly on hover.

360 degree robot

The robot in the card is a live 3D model on a stage that rotates at 45 degrees per second. Change Degrees Per Second on the Pivot object under RobotTurntableStage to speed it up.

Still to do

Please check the LandRobot direction

The right-hand robot was changed and saved, but nobody has confirmed it in Play mode yet. If it still walks backwards, change Front Yaw Offset on its RobotController to 90 or 180.

  • Menu polish: the mockup has a glow, gear icons, a play arrow and turn arrows. The menu uses Unity's default font, not a custom one.
  • Three placeholder buttons: Unlimited Mode, Upgrades and Settings need real screens.
  • Swim robot: it needs a rig and an animation before it can be used on the Ocean map.
  • Old copies: do not open xsollar new\SampahCleaner or xsollar_gamejam\SampahCleaner. They are older and will drift out of date.

Do not rebuild the menu without reading this

The editor command Sampah Cleaner > Build Main Menu UI recreates the whole menu. It replaces the turntable robot with a flat image, so the 360 degree stage has to be set up again afterwards.

Script files for the menu are in Assets/Scripts/UI: MainMenuController, MenuButtonFX and RobotTurntable. The editor builder is in Assets/Editor.
